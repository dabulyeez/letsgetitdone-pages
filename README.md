# Let's Get It Done: public pages

Browser tools served by GitHub Pages. Each page is one self-contained HTML
file. Anything you type in them (symbols, saved IPs, keys) stays in your
own browser's storage and is never sent to this repository.

- `index.html`: home page linking every tool
- `monitor/live-watch.html`: live crypto and stock prices with your own entry, stop and target alerts. Watches only; it never trades.
- `monitor/ip-watch.html`: paste sign-in activity, map the IP addresses, flag the ones that aren't yours
- `monitor/ip-globe.html`: the same check on a 3D globe
- `monitor/street-map.html`: 3D street map

This repository is public. Never add personal details, case files or account information to it.
